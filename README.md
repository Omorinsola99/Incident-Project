# Incident-Project
This project analyzes incidents of violence across Nigeria, including killings, banditry, kidnappings, and other related vices affecting Nigerian States. It aims to create awareness, provide structured data, and highlight patterns that often go unnoticed or underreported.


About Me

I'm a data analyst focused on turning messy, real-world datasets into clear, decision-ready insights — from spreadsheet-level cleaning to dashboard-level storytelling. This project reflects how I approach ambiguous data: audit it thoroughly, clean it defensibly, and present findings that someone can actually act on.
